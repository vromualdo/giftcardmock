Bradescard: telas e dados

Fluxo de telas do app Android mx.com.appbradescard, versão 20260821.1, com os campos, botões, argumentos de navegação, mensagens e contratos de API de cada tela. Extraído do APK, sem executar o app.

Textos vêm do arquivo de strings do app (espanhol, México). Boa parte do conteúdo das telas é entregue pelo servidor (CMS Magnolia), por isso telas em Compose e de pagamentos têm poucos textos locais e mais contratos de API. Nomes de campos de modelos de domínio estão ofuscados no APK, então só os objetos de API (request e response) aparecem com os campos reais.
